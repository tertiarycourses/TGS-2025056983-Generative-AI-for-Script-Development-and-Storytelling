## About the course

This course follows a practical script-to-screen workflow. Learners use generative AI to explore story premises, build characters and worlds, structure scenes, write and revise scripts, design coherent storyboards, plan multimodal production, and document ethical, bias, copyright and provenance controls. Human creative direction remains the decision-making authority throughout.

## Learning outcomes

- Use generative AI techniques to develop compelling script elements enriched with narrative structure and creative storytelling.
- Identify effective prompt terms and narrative components to enhance AI-generated storyboards for visual storytelling.
- Utilise generative AI tools to refine video scripts for clarity, tone, and narrative consistency.
- Analyse generative AI outputs for ethical issues, bias, and copyright risks, applying appropriate corrective actions.
- Identify copyright risks in generative AI production and apply corrective actions to avoid copyright infringement.

## Topics covered

- Story architecture, world-building and character systems
- Prompt contracts, storyboard grammar and visual continuity
- Script analysis, revision and multimodal production
- Bias, authenticity and responsible creative control
- Copyright, provenance and release governance
